    Where the cycle is thinnest

    Refactor candidates

    Package pairs that depend on each other. Sorted by the weaker direction: a single class edge going the "wrong" way is often the cheapest place to break the loop.

    Emergent subsystems

    Louvain communities on the class graph

    Groups of classes that reference each other more than they reference the rest, found without looking at package names. Where a group spans packages, the code is organised differently from the folders.

    Show edges

    Form routing from config

    Rounded nodes are payload forms; boxes are places. Arrows into a place are its routing keys (stage and cost); arrows out are forms it sets.

    Hotspots

    Commits × complexity

    Classes that change often and have many branches. These are where bugs and review effort concentrate. "Test classes" counts test classes that reference the class at all.
